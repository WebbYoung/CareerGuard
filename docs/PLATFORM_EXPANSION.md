# 职安职业成长平台扩展实施计划

日期：2026-11-05。按用户明确要求直接执行。

目标：保留 OCR、隐私、风险和职业规划，在规划之后添加岗证形式的技能依赖树、AI考试、错题练习和多轮语音面试，提供账号与后台运营。

技术：FastAPI、原生 HTML/JS、SQLite、scrypt 密码散列、Fernet 密钥加密。岗证源码只读参考，不修改另一项目。不引入前端构建部署。

数据边界：原始上传文件不落盘，旧材料仍只在内存。用户主动保存的个人资料、脱敏简历摘要、技能树、考试和点评持久化。后台密钥加密，主密钥存本机运行目录，源码包排除运行目录。AI生成资料不当作事实认证。浏览器语音识别可能调用浏览器厂商服务，显式勾选后启动。

实施顺序及验证

- [x] 账号与数据库。新增 app/database.py、platform_api.py，注册登录、退出、禁用即时生效、个人档案。首次注册原子创建管理员，页面明确说明。测试密码不明文、会话轮换、越权和CSRF。
- [x] 岗位与运营。推荐岗位、普通用户自建岗位、评分点评及管理员隐藏、统计、用户管理、固定官方地址下的密钥模型配置。测试普通用户不能访问后台或修改他人内容。
- [x] AI成长。新增 services/growth.py，用严格JSON模型验证技能图无环和前置引用、考试答案服务端保存、错题归属和随机练习、多轮面试按账号隔离。测试畸形模型输出、答案不泄漏、跨用户ID和重复提交。
- [x] 原生前端。新增 platform.js/css，规划报告后继承岗位与技能，技能画布连线/缩放/详情/完成记录，考试、错题、个人中心、后台、面试语音状态机。测试语音拒绝/不可用、退出时释放麦克风。
- [x] 回归和本机验收。完整pytest、JS语法、真实AI生成树/出题/追问、浏览器主要流程、更新启动说明和源码包。

验收重点：生成失败保留已有树、跨账号不泄露数据、考试正确答案在提交前不可见、管理员禁用立即撤销会话、密钥不出现在API响应/日志/源码包、麦克风在离开面试时停止。

实时语音采用语音识别→文本AI追问→语音合成的逐轮低延迟会话，支持实时转写和中断朗读；不是原生音频到音频模型。服务不可用时明确告知并允许文字交互。

验收：68项Python测试、3项语音状态机测试及JS语法通过。真实AI与浏览器验收见PLATFORM_GUIDE.md。实体麦克风未验收。独立审查5项问题已逐项修复，关键边界追加回归。
