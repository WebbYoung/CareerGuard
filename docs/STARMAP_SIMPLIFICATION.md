# 星图连线简化 · v0.9.0

## 已批准范围

总览默认只保留学习起点与职业方向的导航线；共享技能在展开职业后查看。默认按阶段折叠，点击分组或阶段按钮展开技能。点击技能只显示其直接前置与后续关系，完整前置清单继续保留在详情。完整依赖开关仅展开当前职业的真实依赖。底层共享ID、前置关系、考试解锁、覆盖率与用户记录保持原语义。

## 显示规则

- 总览：N个职业只显示N条导航线。
- 职业初始视图：最多四个阶段分组及五条阶段导航主干；缺少某阶段时自动跳过。
- 选择技能：显示直接前置和直接后续，必要邻居自动可见；不自动绘制递归祖先的所有连线。
- 完整依赖：展示当前职业依赖闭包，支持随时收起。
- 阶段分组使用保留ID前缀 `@stage:`，与模型技能ID域隔离，不计入技能数或考核。
- 导航主干为显示引导，不作为实际前置关系；画布提示明确区分两者。
- 保留节点拖动、鼠标锚点滚轮缩放、避让、键盘操作及减少动态效果适配。流动粒子仅出现在当前选中技能的已完成关系，最多两条。

修改前基线：`v0.8.0-starmap-baseline`。本次交付：`v0.9.0`。本地Git历史用于查看差异与回退；未配置或推送远程仓库。密钥、运行数据库、缓存、虚拟环境与模型权重不纳入Git。
