# 职业成长星图实现方案

用户已指定星图、深色科技风、共享技能、有向依赖、考试解锁，并确认正式模式动态生成职业数量；九职业只用于演示。

1. 扩展技能schema的阶段与资源占位，职业schema的核心技能与建议项目。校验全图ID、依赖无环、技能名唯一、职业技能引用。兼容历史单职业数据。
2. 真实进度使用独立考试进度列，保留历史自记进度。单技能考核至少3题且正确率80%，服务端核验前置和考试归属后解锁。公开进度接口不允许直接添加完成项。
3. 新增星图渲染模块与样式。总览中央学生、共享基础环、动态职业环；聚焦职业展示同一全局图的依赖子图与汇合关系。复用已验证的有界拖动控制器。
4. 演示九职业使用独立静态课程图和内存进度，可加载部分完成、节点演示解锁和重置；不调用完成进度API。
5. 键盘、窄屏、reduced-motion、真实考试链和越权测试；浏览器截图验证；更新源码包。
