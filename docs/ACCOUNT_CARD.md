# 个人资料卡

个人中心点击头像可选择PNG、JPEG或WebP静态图片（最大4MB、1600万像素）。服务器仅在内存处理原图，按EXIF校正方向后居中裁切为256×256 PNG，清除元数据；处理图加密保存在SQLite的account_details表。GET头像只允许当前账号读取，不公开任意用户头像端点。

点击“编辑资料”可修改昵称（24字）、城市（40字）和个人简介（160字），并可恢复默认头像。留空昵称时使用登录账号。页面顶部、侧边栏和个人卡片同步显示保存的昵称与头像，登录名和权限不可通过资料接口修改。

删除个人档案与学习记录会同时删除个人资料卡信息和头像，界面已明确说明。上传与保存沿用Session、CSRF和账号数据代数保护。

验证：8项专项后端测试覆盖存取、账号隔离、加密、清空、格式、大小、CSRF；头像不被特效图标替换的Node回归测试通过。完整测试165项Python、47项Node通过。浏览器使用独立localhost:5090合成资料验证上传、保存、刷新恢复和390px编辑弹窗，不修改现有用户资料、不调用模型。
