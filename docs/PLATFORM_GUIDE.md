# 新版职安：账号、AI成长与平台运营

更新日期：2026-11-05。服务仍用 start.bat / start.ps1 启动，本机地址为 http://127.0.0.1:5088/。

## 页面入口与默认管理员

首页 `/` 提供用户工作台、访客演示和管理入口。登录 `/login` 与注册 `/register` 为独立页面。前台工作台 `/app` 需要登录，管理后台 `/admin` 使用独立HTML、脚本和导航，不再嵌入前台。

按用户明确指定，默认超级用户为 `admin`，初始密码为 `admin`。本次升级完成一次默认账号迁移，已有同名账号按本次指定初始化，此后启动不再重设密码。数据库只保存带随机盐的密码散列。原有其他账号保留，普通注册账号一律为普通用户，注册密码仍至少10位并包含多种字符。

访客从 `/demo` 进入固定合成样例，可体验风险线索、脱敏预览和职业规划。访客没有材料上传、AI生成、考试保存、点评发布或个人资料保存权限，服务端也会拒绝完整功能API。访客演示不调用真实大模型，不接收自定义材料。

## 职业规划到技能考试

1. 原有流程添加简历和岗位JD，生成差距报告。
2. 报告后点击「进入AI职业技能树」。页面带入岗位描述和报告中的技能缺口，也可以直接输入目标职业。
3. 预览文本、勾选AI发送说明，生成技能树。布局参照岗证的自定义技能树：分层节点、曲线连线、前置条件、画布滚动缩放、右侧技能与交付物详情。
4. 完成实践后可以自行记录进度。撤销前置技能会同步撤销依赖节点，完成状态不是能力认证。
5. 勾选1–8个技能，确认模型发送范围后生成考试。模型通常生成5道四选一题，接口允许1–8道合法题。
6. 提交后服务端判分并显示解析，答错题目自动进入错题本。个人中心可随机抽取最多5道错题复习，重复正确会增加连续答对次数。
7. 个人中心可以查看考试记录、恢复未提交考试、查看或继续面试。

模型技能树先校验重复ID、引用有效性和无环依赖。答案与解析仅服务端保存，考试提交前不发给浏览器。模型失败、未配置、余额或输出格式异常会显示错误，不伪造成功结果。AI题目及解析可能有误，需要核对课程和专业资料。

## AI语音面试

在「AI面试」填写或继承岗位，确认发送岗位及回答到模型，点击开始。AI逐轮提出问题，根据回答给出反馈并继续追问，最多12轮。只做模拟练习，不验证经历真假，不预测录用。

文字方式直接输入并发送。启用语音须额外勾选语音说明，允许浏览器访问麦克风。浏览器实时显示转写，用户可以修改。开启自动发送后，在检测到停顿并结束识别后自动提交，再朗读下一问。可随时停止听写、打断朗读、结束面试。单次语音硬上限3分钟，单轮文字最多2500字，离开页面、切换后台、退出或清空会停止语音。

这里采用浏览器 Web Speech API，而非DeepSeek原生音频模型，也不是全双工音频通话。识别服务由浏览器提供，可能将音频发送到浏览器厂商的服务。DeepSeek只接收脱敏文字。浏览器不支持、权限拒绝或网络失败时保留文字入口。本站不上传或保存音频文件。

参考依据：[MDN SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)、[Microsoft Edge语音识别说明](https://learn.microsoft.com/en-us/microsoft-edge/web-platform/speech-recognition-api)、[DeepSeek结构化JSON输出](https://api-docs.deepseek.com/guides/json_mode/)。

## 岗位、点评与管理后台

「岗位推荐」展示管理员推荐与用户分享，可搜索、用于职业规划、查看或提交个人体验点评。推荐不代表招聘主体或岗位已核验。点评先做长度、PII和注入检查，不允许外部链接及简单的未经核实定性指控，但规则不能代替完整人工审核。

管理员登录后可见「管理后台」，提供用户/岗位/点评/技能树/考试/面试数量、今日活跃账号、操作类型统计和近14个活跃日统计。统计日按UTC分组。

管理员可停用/启用用户，停用立即撤销登录会话，不能停用当前管理员。可在岗位推荐页面勾选管理员推荐后发布公司岗位，在后台下架岗位。可以隐藏/恢复用户点评，作者更新内容不会自行解除管理员隐藏。

后台支持DeepSeek官方服务或本机Ollama的模型名称与API Key配置、连接测试。留空密钥保留现有值，密钥永不回显。为延续SSRF防护，接口不接受自定义模型URL。

## SQLite数据与备份

运行数据默认在 `.runtime/platform.sqlite3`，主密钥在 `.runtime/master.key`。模型配置使用Fernet加密，账号密码使用带随机盐的scrypt散列，登录Cookie在数据库仅保存摘要。数据库使用参数化SQL、外键和WAL，服务继续只绑定本机回环地址。

数据库存账号、主动保存的脱敏简历摘要、岗位、点评、树与进度、考试、错题、面试文字和无正文运营事件。原始上传图片/PDF字节用于即时解析，不存文件副本。正式账号的解析文本、OCR行信息、风险与脱敏结果、职业报告均按账号存入SQLite。退出切换账号释放临时材料，登录采用服务端Session：浏览器持有HttpOnly、SameSite会话Cookie，数据库仅保存随机令牌摘要。服务端按活跃请求续期，闲置上限7天。临时内存重建不会使有效账号登录失效。访客演示闲置30分钟清空。

「清空本次数据」释放临时材料与当前展示内容，不删除账号下主动保存的记录。「个人中心→删除个人档案与学习记录」单独删除档案、路线、考试、错题与面试，保留账号和已发布岗位点评，并阻止在途生成任务重新写回。

备份时先停止服务，再将整个`.runtime`目录作为敏感资料单独保管。数据库和主密钥应共同备份，源代码交付包排除`.runtime`、`.env`和模型权重。删除SQLite记录不等于磁盘取证级擦除，备份中的历史资料需另行管理。

## 正式用户与访客的数据区别（最新规则）

正式用户界面不显示“数据只在此刻”“30分钟临时过期”或合成样例入口。个人材料、OCR行信息、风险/脱敏结果、职业报告和学习记录存入SQLite，个人中心可重新打开、删除材料或查看已保存报告。访客页面保留固定合成演示说明和清空功能，不上传或保存个人数据。正式账号访问访客页会回到工作台。原始文件二进制仅在解析时使用，不额外保留图片/PDF文件。

登录采用服务端Session、浏览器会话Cookie、7天闲置滑动过期，退出会撤销服务端Session。已保存资料不会随退出、页面关闭或内存缓存清理而删除。73项Python测试通过，包含重建内存与重新登录后的材料恢复。
