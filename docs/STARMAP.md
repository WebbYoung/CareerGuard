# 职业成长星图

## 两种数据来源，同一星图交互

正式模式：适用任意专业，新增“专业 / 学习领域”输入并随路线保存，中央学习者称呼随专业变化。填写专业后可不填目标岗位，由AI探索相关方向。从职业规划带入目标岗位、JD与技能缺口，也可打开“由AI定制职业路径”手动输入。AI动态生成职业方向和共享技能，职业数量按输入决定（结构上限12方向、64技能），不是九方向模板。旧版单职业路线仍可读取，阶段和资源缺失时采用兼容默认值。

演示模式：预置九方向、35个共享技能节点。点击“一键加载成长进度”，选择前端项目节点并“演示通过考核”，展示87.5%到100%的技能覆盖率和路径成就。演示完成仅修改页面内存；重置不修改SQLite，离开演示切回个人图显示个人考核记录。

## 字段与依赖

技能：id、name、description、stage（公共基础技能/职业方向/专业技能/项目实战）、prerequisites、resources（资源说明或占位，不自动访问链接）、task；status和shared_count从数据派生，不采信AI自报完成。

职业：id、name、description、core_skill_ids、projects；required_skill_ids包含核心技能的前置依赖闭包。服务端计算required_count、completed_count、coverage、mastered和missing。共享技能保留同一ID，禁止重复ID、循环、未知引用、无归属技能以及多职业完全分离的副本。

技能覆盖率 = 已完成必备技能数 / 必备技能总数。覆盖率与成长等级均为学习进度，不是认证、能力证明或招聘录用概率。

## 考核解锁

正式节点考核通过 `/api/learning/exams` 发送 unlock=true，单次只能选择一个技能。服务端先核对前置与记录归属，AI须返回至少3道不同题目。通过 `/submit` 服务端判分，正确率达到80%且提交时前置仍满足才新增完成记录。普通自由练习、错题练习、前端提交完成列表和旧版自我记录不会解锁技能。

旧版 trees.progress 原样保留，新的 trees.assessment_progress 保存正式考试进度；exams.unlock_node绑定考核节点，重复提交返回409。模型等待期间继续使用原有数据代数检查，删除个人资料后的迟到模型结果不会写回。

## 浏览和可访问性

总览采用学生中央节点、共享基础环与职业星座；聚焦职业后展示全局共享图的依赖子图，不复制技能。窄屏总览隐去内圈细节以保持职业名称可读，聚焦后完整展示必备技能。按钮保持可读尺寸，缩放只缩放节点坐标和连线。支持鼠标/单指有界拖动，节点点击与拖动阈值分离，详情面板不参与画布手势。

Tab聚焦，Enter/Space选择，节点上的方向键移动焦点，画布方向键滚动，+/-缩放，Home适配居中，Escape取消选择。按钮提供返回职业总览、画布居中和重置演示。节点反馈150ms，进度过渡200ms，成就240ms；最多6条路径显示短时能量流动，静态星点不持续运算。prefers-reduced-motion下不创建流动粒子，关闭缩放、进度和成就动画；键盘操作也不播放缩放动画。

## 验证

- Python回归包含schema、共享闭包覆盖率、前置拦截、考核通过/失败、自由练习不解锁、旧版数据保留、重复提交和用户隔离。
- Node测试包含演示九职业、正式动态两职业、共享节点不复制，以及有界拖动和误触抑制。
- 实际DeepSeek生成了双职业、11技能的星图。真实5题节点考核完成后，SQLite进度为1/11，两个方向的覆盖率为16.7%与14.3%，刷新后保留。
- 浏览器验证演示部分进度、项目解锁、成就反馈、切回个人进度隔离；1440px桌面双栏、390px窄屏无页面横向溢出；Enter/方向键/Escape可操作。模拟减少动态效果时粒子数0、节点与进度过渡均0s。
- 未对实体手机或低端设备的帧率进行硬件实测。

## 节点布局与鼠标交互更新

鼠标滚轮在画布内以指针为锚点缩放，通过requestAnimationFrame合并同帧输入；空白区域拖动平移画布，按住节点拖动只更新该节点和关联连线。初始布局及缩放结束后按屏幕文字尺寸避让，节点松手时选择邻近空位。当前页面内按正式/演示及职业焦点分别保留手动位置，“重新排布”恢复自动布局；Alt+方向键可移动聚焦节点。节点长标题最多显示两行，完整名称保留在无障碍名称和详情中。
