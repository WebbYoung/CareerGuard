# 技能树交互验证

画布通过 Pointer Events 统一鼠标和单指输入，使用浏览器原生有界滚动整体移动节点与连线。超过6 CSS像素即判定拖动，直到手势结束持续抑制点击；轻微抖动仍按点击处理。使用指针捕获处理移出画布的抬手，保留按下的节点标识，避免捕获改变 click 目标造成误选。双指介入和 pointercancel 中断平移。

节点点击仅更新选中类名、关联连线及详情，不重新创建画布节点。悬停缩放1.025，按下缩放0.97；触屏不使用悬停效果。反馈150ms、详情160ms，使用已有 --ease；减少动态效果设置下关闭缩放和过渡。详情与考试区域在画布外，不参与平移。缩放保留出题范围，回到初始位置恢复100%缩放和左上起点；Escape关闭详情。

验证：`node --test tests/test_tree_canvas.mjs tests/test_camera.mjs tests/test_voice.mjs`。交互测试覆盖拖动、轻触、移动边界、误触抑制、取消、多指中断、键盘点击和指针捕获重定向。浏览器使用AI生成的匿名Python岗位12节点路线，验证了真实鼠标拖动、空白取消、节点切换、关联线高亮、详情隔离及复位；1366px桌面双栏与390px窄屏无页面横向溢出。单指行为由状态测试验证，未对实体手机硬件实测。
