# 结构化生成错误修复

提示“模型未返回合格的结构化结果，原记录保留，请重试。”来自技能树、技能考试和面试共用的growth.generate_json。代码检查确认：自定义模型请求缺少原生JSON输出格式约束，解析直接要求完整裸JSON，格式包装、字段缺失、截断及服务异常又共用兜底提示。

## 修复

- OpenAI兼容请求使用JSON object模式；DeepSeek官方地址禁用思考输出以保留结果预算。Ollama使用JSON schema格式。Anthropic使用唯一强制submit_result数据封装工具，不执行任何业务工具。
- 仅提取一个有界JSON对象，支持BOM、完整think包装、单个JSON围栏及短说明文字；拒绝重复键、多个JSON值、非有限数字与不完整JSON，不靠补括号伪造完整结果。
- 必填字段、长度、答案范围、技能ID/依赖/环路等原校验保留。格式或字段失败时，仅附校验摘要，最多自动修正一次。原始输入继续视为不可信材料，不按模型指令执行操作。
- 显式截断不保存；提示减少生成范围。服务不可用、协议异常与字段校验失败分别报错，不再全部误报为结构不合格。
- 日志只记录schema名、错误类别和尝试次数，不记录用户输入、模型原文、密钥或个人信息。所有数据库写入仍在完整校验与原有账号并发校验之后。

## 验证

15项新增离线测试覆盖三种协议、JSON包装、缺失字段后单次修正、重试上限、重复键/多个值、循环依赖、截断、网关异常，以及失败后数据库原记录逐字不变。全套207项Python测试通过。测试统一阻断真实网络，未读取真实用户材料或调用远端模型。
