# 小安机器人引导

机器人参照用户提供的白色圆头、黑色面罩、蓝眼睛与白色双臂形象，以Three.js几何体绘制。首页右侧可进入工作台，工作台右侧可重放引导。

## 交互
- 新注册账号在首次进入工作台后自动启动，十步覆盖全部主要前台模块。
- 机器人移动到目标附近，抬起对应手臂指向高亮区域，显示气泡。
- 点击“我明白了”继续，可上一步或随时跳过。Escape关闭，Tab在气泡内循环，关闭后恢复页面交互与焦点。
- 进度按账号存入SQLite。刷新可继续，完成/跳过后不自动重复；旧账号不强制弹出。
- 引导只介绍控件，不触发材料、模型、考试或媒体权限业务。
- 手机会重新安排机器人与气泡。减少动态时直接切换位置与姿势；关闭特效时机器人保持静态。

## 源码
- static/robot-model.js：独立Three模型、灯光、双臂、指向及渲染生命周期。
- static/vendor/three/：Three.js0.187.0官方npm包，SHA512校验，本地依赖及MIT许可随源码交付；运行时不访问CDN。
- static/guide-core.js：固定十步内容、视口布局与并发启动门控。
- static/guide-assistant.js/.css：工作台的模态引导、进度接口和焦点恢复。
- static/robot-welcome.js：首页入口。
- app/onboarding_api.py及services/onboarding.py：当前Session账号下的引导状态接口。
- user_guides表：user_id/guide_id/status/step/updated；只存界面进度。

## 兼容
浏览器无WebGL或图形上下文丢失时，使用用户提供图片的未修改副本作静态形象，文字引导仍可用；静态降级无法抬臂。普通3D模式已在浏览器实际验证。

## 验证
新注册初始化、账号隔离、退出重登、完成/跳过、CSRF与步骤校验由独立测试数据库验证。
浏览器验证：十步切换、刷新续接、完成后不重复、手动重放、手机边界与跳过后解除inert/滚动锁。
自动GET与手动POST乱序的回归用例先失败后通过，重复进入不会覆盖模态原始状态。
