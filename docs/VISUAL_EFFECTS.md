# 强化视觉效果

参考：https://github.com/sunyctf/js-effects 。已查看星云粒子、网状粒子、3D卡片悬停实现；采用独立的原生实现，不加载仓库演示脚本或jQuery。

## 已接入
- 静态毛玻璃材质：18–24px背景模糊、透光背景与边缘高光。
- Canvas动态星场、粒子连接、鼠标连接、流星雨、点击微粒。
- 多层极光光场、卡片环绕光带、外沿炫光、鼠标聚光。
- 展示卡片3D倾斜、按钮涟漪、盾牌与插画悬浮、标题色彩流动。
- 十六枚统一玻璃图标，图集由本项目生成；用SVG亮度alpha移除黑底并按原控件语义显示。
- 全开/轻量/关闭三档。隐藏页面暂停，系统减少动态时停止连续效果。

## 模块与限制
- effects-core.js：纯粒子数学、连线上限、唯一帧循环，Node测试覆盖重复开启、暂停与过期回调。
- effects.js：Canvas、DOM渐进增强、图标与卡片观察。只观察childList，不监听或记录输入值。
- effects.css：毛玻璃与合成层动画，聚光用独立裁剪层避免水平溢出。
- 默认桌面最多92粒子、90条近邻连线、8流星，Canvas最多200万物理像素；绘制调度上限30fps，手机上限24fps。此为预算上限，并非真实设备帧率保证。
- 全开是默认值；档位只在当前页面内存保存。
- 未经真实手机性能录制；已通过浏览器390px布局和系统减少动态验证。
