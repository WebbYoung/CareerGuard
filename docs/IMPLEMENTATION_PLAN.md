# 求职安全体检平台实现计划

**目标**：以 Python + 原生 HTML/JS 完成用户指定的五模块及比赛演示闭环。

**架构**：FastAPI 同源服务；材料和审计仅存内存；PaddleOCR 仅接收内存图像；本机 Ollama 负责受约束 JSON 解释。规则检测与本地知识检索提供可追溯依据，未配置模型时明确降级。

**全局约束**：不请求材料中的链接；不存原始材料；不包含真实身份信息；不做 ASR 或模拟面试；无外部前端资源；单进程本地运行。

## 重点验证

1. “不收押金”不得与“先交押金”采用同一风险命中。
2. 拒绝伪装文件、过量页面、超大图像和超限流式请求；不使用会落盘的上传组件。
3. 恶意材料不得进入 LLM；LLM 失败不伪造模型结论；未知技能不能被打成完全匹配。
4. 两个浏览器会话不能读取对方材料；清空期间完成的任务不得把材料写回。
5. 页面用文本节点显示用户数据；导出只允许脱敏版本；清空后前端不保留原文。
