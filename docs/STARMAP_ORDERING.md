# v0.9.1 · 有序展开布局

## 原因

旧布局将同阶段技能均分到整个环上，再逐个螺旋避让；展开分组后沿用这些环形位置，子节点看起来四散。现在总览继续使用星图，但职业细节采用稳定的阶段网格，不再依赖逐节点螺旋推散。

## 排列规则

1. 专业的实际技能与前置关系保持不变。以全图前置深度确定学习次序；同层按中文名称、唯一ID稳定排序。
2. 每阶段按全部必备技能预留固定单元，不随是否选中、完成状态或显示子集重新分配位置。少量技能单列，三项以上双列，从左到右、从上到下编号。
3. 各阶段预留固定栏宽，展开时把对应分组及前两行定位到可视区域；其余分组不换位。更多内容可继续拖动和缩放浏览。
4. 节点距离按可读尺寸预留，格距为164×144像素的参考尺度。放大不重新紧缩排布；缩小到文字可能遮挡的尺度时保持可读间距。
5. 用户手动位置按当前页面和职业上下文保留。拖动总分组时，已展开子节点保持相对位置整体跟随；碰撞、边界与画布尺寸检查按整个节点簇计算。
6. 完整依赖模式也采用相同学习排序。界面分组和序号不写入技能库，不影响考核和技能覆盖率。

## 验证

新增布局测试覆盖模型节点输入反序、真实前置顺序、分组锚点稳定、无节点遮挡、分组平移、整组碰撞/边界与缩放坐标稳定。独立复查发现的整组碰撞和边界问题已修正并复查通过。

本次验证：30项前端测试、88项Python回归测试通过。浏览器确认四项设计基础技能以2×2网格显示，收起再展开时坐标相同；分组键盘移动时全部子节点保持相对距离，390px窄屏无页面横向溢出。截图见 `starmap-ordered.png`。
