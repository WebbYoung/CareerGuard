# 职安沉浸式前端改版实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将已批准的三张设计稿组合为全站深色科技风：1首页、2侧边栏与工作台、3职业星图。
**Architecture:** 保持FastAPI和原生JS业务接口，新增独立视觉层与渐进增强动效。真实图谱继续使用原有DOM节点、SVG连线、拖拽缩放控制器；不替换数据与解锁规则。
**Tech Stack:** HTML、CSS、vanilla JS、生成的玻璃盾牌静态素材。
**Spec:** 用户本次明确批准的组合方案与对话内三张视觉稿。

## Global Constraints
- 所有业务ID、同意勾选、账号隔离、权限、审核、隐私与风险声明保留。
- 不读取密钥；不改变数据库及个人材料；不新增外链抓取与第三方前端CDN。
- 深黑与冰蓝/蓝紫，正常正文14–16px；侧边栏采用第二张，星图采用第三张。
- 减少动态偏好下禁用位移和视差；无JS仍可访问页面内容与真实链接。

## Review Focus
- 390px窄屏不得横向溢出，触摸画布行为保留。
- 动态平台模板插入后仍能应用样式；导航、同意和考试按钮正常。
- 长职业名称和多专业图谱不被样式裁切；节点变大后布局参考尺度一致。
- 开启减少动态后不播放装饰动画，隐藏页面停止视觉更新。
- 装饰图片没有业务含义与事件，不遮挡输入和真实节点。
