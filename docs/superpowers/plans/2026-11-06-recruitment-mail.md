# 后台分页面与招聘沟通闭环

目标：网站后台与企业后台使用左侧导航独立页面、统一玻璃图标和完整特效；求职者通过已审岗位准备面试并主动授权投递简历；企业仅查看本企业有效授权用户与去重面试人数；站内邮件实时收发，SMTP为可选外发。

实施：
- [x] AdminPages query路由和企业路径路由，前进后退/直达/表单保留。
- [x] 授权简历快照加密，撤回删除快照，真实面试关联服务端建立。
- [x] 前台岗位一键准备面试、显式简历授权与AI发送授权分开，私密训练内容不供企业查看。
- [x] 站内收发、长轮询未读提醒、邮箱验证码和主动接收授权，SMTP保存不探测、TLS公有IP绑定。
- [x] 角色隔离、CSRF、输入校验、最小审计、并发删除保护，旧异步界面不能复活已清空内容。
- [x] 独立合成环境跨角色浏览器验证、全套离线测试与集成审查修复。
- [x] 交付说明、源码包与本地版本记录。

职责：网站admin UI、企业招聘、邮件三个独立子任务按并行开发技能分派；根负责共享schema/router、岗位面试API/前台桥、跨模块审查和验证。

约束：不读取现有用户数据或密钥；真实模型、Embedding、SMTP仍不实测；浏览器仅向独立测试账号发站内消息。企业材料审核不等于政府认证；面试人数不等于招聘评分或录取预测。
