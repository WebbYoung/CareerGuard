# 机器人首次使用引导实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 根据用户给定机器人形象，在右侧提供可移动、抬臂指向目标的3D助手，为新注册账号提供可确认/跳过的首次引导。
**Architecture:** 本地Three.js模型独立渲染，guide-core.js定义十步流程和视口布局，guide-assistant.js控制焦点、气泡与高亮。SQLite只保存账号引导版本、状态和步数。
**Tech Stack:** 原生JS、Three.js0.187.0（官方npm包本地vendoring）、FastAPI、SQLite。
**Spec:** 本次用户机器人图片与明确交互要求；继续保留正在进行的特效增强。

## Global Constraints
- 新注册账号自动启动，旧账号不强制弹出；右侧机器人可手动重放。
- 未经用户点击不上传材料、不调用AI、不打开摄像头或麦克风。
- 引导仅介绍控件，不执行真实分析、考试、导出、提交等业务动作。
- 步数和状态按账号保存；沿用Session与CSRF校验；不接受其他用户ID。
- 减少动态时位置与抬臂直接切换；隐藏页暂停模型；无WebGL仍显示气泡和控件。
- 提供我明白了、上一步、跳过引导，Escape可关闭；焦点限制在引导气泡且关闭后恢复。

## Review Focus
- 小屏气泡/机器人/目标不遮挡按钮，视口边界内放置。
- 初始化先后顺序、快速跳过/继续、网络失败不能困住用户或复活已关闭引导。
- SQLite账号隔离、退出重登保留状态、完成后不重复自动启动。
- Three模块本地加载，MIT许可与依赖路径完整，模型资源有释放。
- 模态层阻断危险业务点击，但不自动聚焦输入而弹出手机键盘。
