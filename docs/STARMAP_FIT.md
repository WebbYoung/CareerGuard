# v0.9.3 · 适配全图

原问题来自20%固定缩放下限、节点逆缩放保持尺寸，以及缩放结束后按新比例重新排列网格。三者使图在缩小后仍被撑大。

现在布局在固定参考尺度生成，缩放只改变整个场景；节点、文字与连线一起缩放。拖动、碰撞和锚点沿用固定参考尺度，缩放不再重建或推散网格。

“适配全图”和Home读取当前可见节点及其文字的实际世界包围框，按画布宽高与32px留白计算比例，再将内容中心对准视口。可低于20%，不重置进度或手动节点位置。点击阶段展开时仍会恢复到可读尺度以便学习。

验证：32项前端测试通过，包含超大内容低于20%的适配及节点包围框回归；独立复查无新增问题。浏览器完整依赖视图10个节点在1440px桌面35%和390px窄屏12%时均全部位于画布范围内，无页面横向溢出。
